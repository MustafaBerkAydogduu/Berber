## 📌 Proje Hakkında

Bu proje, **Kuaför Nurkan Aydoğdu** salonunun hizmetlerini, çalışma saatlerini, stil portfolyosunu ve iletişim bilgilerini ziyaretçilere modern ve şık bir arayüzle sunmak amacıyla hazırlanmıştır.

---

## 🛠️ Temel Özellikler

* **Mobil Uyumlu Tasarım:** Telefon, tablet ve masaüstü cihazlarda akıcı çalışan responsive kullanıcı arayüzü.
* **Hızlı Randevu Sistemi:** Hizmet seçimiyle birlikte tek tıkla doğrudan WhatsApp üzerinden randevu oluşturma.
* **Hizmet Menüsü & Portfolyo:** Saç ve sakal tasarım seçenekleri ile güncel salon detayları.
* **Yasal Bilgilendirme Modalı:** KVKK, Aydınlatma Metni, Gizlilik ve Çerez Politikalarını içeren modern bilgi penceresi.
* **Arama Motoru Uyumu (SEO):** Google standartlarına uygun meta etiketleri ve yerel işletme yapılandırması.

---

## 💻 Kullanılan Teknolojiler

* **React 18** — Arayüz bileşen mimarisi
* **Vite** — Hızlı derleme ve geliştirme ortamı
* **Tailwind CSS** — Stil ve responsive tasarım
* **Framer Motion** — Sayfa içi geçiş animasyonları
* **Lucide Icons** — Vektörel minimalist ikon seti
* **Vercel** — Barındırma ve kesintisiz yayınlama

## 📂 Proje Klasör Yapısı

```bash
nurkanaydogdukuafor-web/
├── public/
│   ├── favicon.svg          # Altın makas vektör logosu
│   ├── favicon-192x192.png  # PWA & Arama ikonu
│   ├── nurkan.jpg           # Salon & kurucu görseli
│   ├── robots.txt           # Arama motoru kuralları
│   ├── sitemap.xml          # Site haritası
│   └── site.webmanifest     # Web manifesti
├── src/
│   ├── components/
│   │   ├── BrandIcon.jsx    # Logo bileşeni
│   │   ├── Footer.jsx       # Alt bilgi & yasal linkler
│   │   ├── LegalModal.jsx   # KVKK & Gizlilik modalı
│   │   ├── Navbar.jsx       # Üst navigasyon menüsü
│   │   └── WhatsAppButton.jsx # Kayan randevu butonu
│   ├── sections/
│   │   ├── About.jsx        # Hakkımızda & vizyon
│   │   ├── FAQ.jsx          # Sıkça sorulan sorular
│   │   ├── Gallery.jsx      # Salon ve stil galerisi
│   │   ├── Hero.jsx         # Karşılama manşeti
│   │   ├── Services.jsx     # Hizmetler & bakım menüsü
│   │   └── Testimonials.jsx # Misafir değerlendirmeleri
│   ├── App.jsx              # Ana uygulama düzeni
│   └── index.css            # Stil ve tema tanımları
├── index.html               # Temel HTML & SEO yapılandırması
├── package.json             # Bağımlılıklar ve komutlar
├── tailwind.config.js       # Tema & renk paleti ayarları
└── vercel.json              # Güvenlik başlıkları yapılandırması
```

## 🚀 Kurulum & Çalıştırma

```bash
# Projeyi bilgisayarınıza indirin
git clone https://github.com/MustafaBerkAydogduu/nurkanaydogdukuafor-web.git

# Proje klasörüne girin
cd nurkanaydogdukuafor-web

# Paketleri yükleyin
npm install

# Geliştirici modunda çalıştırın
npm run dev

# Canlı sürüm için derleyin
npm run build
```
